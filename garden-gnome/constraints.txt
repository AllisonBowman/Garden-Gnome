# in the Dockerfile and in CI both get exactly these. A constraints file only
# fixes versions -- it never installs anything itself -- so a platform-specific

# 60 tests (42166bc). To upgrade: bump the direct pin in requirements*.txt,
# rebuild a clean 3.12 venv, run the suite, and regenerate this file with
# `pip freeze --exclude pip --exclude setuptools` from that venv.
#

# not pull in greenlet, so greenlet was added by hand for the Linux image --
